# הדלקת קלוד

שולחים הודעה קבועה ל-Claude Code בשעה שבוחרים, או בשיחה מהטלפון הכשר (מקישים 1).
אחרי הגדרה של פעם אחת, **המחשב לא צריך להיות דלוק**: הכל רץ בענן של גוגל.
הרעיון כמו הסקריפט מהשרשור במתמחים: לפתוח מראש את חלון השימוש של 5 השעות.

## מה מתקינים

`ClaudeWake-Setup-<גרסה>.exe`: התקנה רגילה, בלי הרשאות מנהל. נפתח אשף בשמונה שלבים:

| שלב | מה קורה |
|---|---|
| גוגל | מתחברים לחשבון גוגל (דרך clasp, הכלי הרשמי של גוגל להעלאת סקריפטים) |
| API | מפעילים מתג אחד בהגדרות של גוגל: Google Apps Script API |
| ענן | התוכנה יוצרת סקריפט בחשבון שלך, מעלה ומפרסמת אותו. מאשרים לו הרשאות פעם אחת |
| Claude | יוצרים ב-claude.ai רוטינה עם טריגר API (האשף מסביר ומעתיק את ההנחיה), ומדביקים את Fire URL והטוקן |
| תזמון | שעה וימים (שעון ישראל, כולל שעון חורף) |
| טלפון | לא חובה: טוקן ימות, שלוחה, קוד כניסה וטלפונים מורשים. השלוחה מוגדרת לבד |

אחר כך התוכנה היא לוח בקרה: כפתור שליחה לכל מקש, תזמונים, יומן, והגדרות מאחורי גלגל השיניים.
אפשר לסגור אותה. היא נחוצה רק כדי לשנות משהו.

## איך זה עובד

```
טלפון כשר ──שיחה──> ימות המשיח ──שלוחת API──┐
                                            ├──> סקריפט בגוגל (Apps Script) ──POST──> רוטינה ב-claude.ai
תזמון (כל דקה, שעון ישראל) ──────────────────┘          ↑
                                                        └── תוכנת הניהול במחשב (רק להגדרה)
```

- **ימות לא יכולים לפנות לקלוד ישירות.** הפעלת רוטינה דורשת בקשה עם כותרת הרשאה, ושלוחת API של ימות לא שולחת כותרות. הסקריפט בגוגל הוא המתווך.
- **הטוקנים נשמרים רק בסקריפט שבחשבון הגוגל שלך:** של Claude ושל ימות. התוכנה במחשב שומרת רק מפתח ניהול.
- **הסקריפט מוגן במפתחות:** בלי מפתח הניהול (128 ביט) אין גישה להגדרות. בלי המפתח הסודי שבכתובת השלוחה אין גישה לתפריט הטלפון.

## דברים לבדוק בהתקנה הראשונה
- **הפניה של גוגל:** Apps Script מחזיר תשובות דרך הפניה. אם בשיחה לשלוחה שומעים "אין מענה משרת API", ימות לא עוקבים אחרי ההפניה, וצריך להוסיף ממסר קטן.
- **נטפרי:** צריך ש-script.google.com ו-script.googleusercontent.com יהיו פתוחים. התוכנה משתמשת בתעודות של Windows, כך שתעודת נטפרי נתמכת.
- **אישור ההרשאות:** גוגל מציג "Google hasn't verified this app", כי זה סקריפט פרטי שלך. לוחצים Advanced ואז Go to הדלקת קלוד.

## מגבלות
- **מכסות:** הרוטינה נספרת במכסת השימוש של המנוי. אם המכסה נגמרה, ההפעלה נכשלת עד שהחלון מתאפס.
- **הגבלה שעתית:** עד 30 הפעלות בשעה לכל רוטינה דרך API.
- **שלב ניסיוני:** טריגר ה-API של רוטינות נמצא ב-Research preview, ו-Anthropic עשויים לשנות אותו.
- **הסרה:** הסרת התוכנה לא מוחקת את הסקריפט בגוגל. מוחקים אותו ב-script.google.com.

## חלופה בלי טלפון: GitHub Actions
התיקייה `github/` מכילה גרסה לתזמונים בלבד, שרצה ב-GitHub Actions ומוגדרת בקובץ `wake.json`. היא לא מקבלת שיחות מימות.
ההתקנה: מעלים את התוכן לריפו, מוסיפים Secrets בשם `CLAUDE_FIRE_URL` ו-`CLAUDE_FIRE_TOKEN`, ועורכים את `wake.json`.

## פיתוח
| מה | פקודה |
|---|---|
| בדיקות | `node --test tests/test_app.mjs tests/test_gas.mjs` ו-`python -m unittest discover -s tests` |
| הרצה מול גוגל ו-clasp מדומים | `node tests/fake/dev.mjs`, ואז `http://127.0.0.1:8789/?t=dev` |
| בניית קובץ ההתקנה | `powershell -ExecutionPolicy Bypass -File installer\build-release.ps1 -Version 1.0.0` |

**מבנה:** `src/` הסקריפט שעולה לגוגל · `app/` התוכנה במחשב (שרת מקומי וממשק) · `installer/` בנייה ו-Inno Setup · `github/` חלופת GitHub · `tests/` בדיקות והדמיות.

clasp נארז לקובץ אחד בבנייה, כי מ-node_modules הוא לא נטען כשבנתיב יש עברית (תיקיית המשתמש).
