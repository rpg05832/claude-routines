# הדלקת קלוד

שולחים הודעה קבועה ל-Claude Code בשעה שבוחרים, ובמסלול גוגל גם בשיחה מהטלפון הכשר (מקישים 1).
אחרי הגדרה של פעם אחת, **המחשב לא צריך להיות דלוק**: הכל רץ בענן.
הרעיון כמו הסקריפט מהשרשור במתמחים: לפתוח מראש את חלון השימוש של 5 השעות.

## התקנה

מורידים את `ClaudeWake-Setup-<גרסה>.exe` מ-[Releases](../../releases) ומריצים. ההתקנה רגילה, בלי הרשאות מנהל.
נפתח אשף, ובו בוחרים איפה המערכת תרוץ:

| | **גוגל** (מומלץ) | **claude.ai בלבד** | **GitHub** |
|---|---|---|---|
| הפעלה מהטלפון (ימות) | כן | לא | לא |
| תזמונים | מדויקים, שעון ישראל | שעון UTC: אחרי מעבר לשעון חורף או קיץ פותחים את התוכנה פעם אחת | מאחרים לפעמים בכמה דקות |
| צריך | חשבון גוגל | Claude Code במחשב (התוכנה מתקינה אם חסר) | חשבון GitHub וטוקן |
| ידני, פעם אחת | רוטינה עם טריגר API באתר claude.ai | רוטינה אחת כלשהי בחשבון, רק אם אין עדיין | רוטינה עם טריגר API, וטוקן GitHub |
| נטפרי | עובד | עובד (צריך תעודת נטפרי ב-Windows) | עובד |

אחרי האשף, התוכנה היא לוח בקרה. יש בה כפתור שליחה לכל מקש, תזמונים, יומן, והגדרות מאחורי גלגל השיניים.

## איך כל מסלול עובד

**גוגל.** התוכנה יוצרת סקריפט ב-Google Apps Script בחשבון שלך דרך clasp, הכלי הרשמי של גוגל.
- **ההגדרות:** נכתבות לתוך קוד הסקריפט. כל שמירה מעלה אותו מחדש, תוך כ-15 שניות.
- **בלי הכתובת החסומה:** התוכנה לא פונה לכתובת הסקריפט, שחסומה בנטפרי. היא מעלה קוד דרך script.googleapis.com, שולחת לקלוד ישירות, ומגדירה את השלוחה ישירות מול ימות.
- **מה רץ בענן:** ימות פונים לסקריפט מהשרתים שלהם, והתזמונים רצים בגוגל. אף אחד מהם לא עובר דרך נטפרי.
- **הרשאות:** פעם אחת מריצים בעורך הסקריפט את `authorize`, כדי לאשר הרשאות.

**claude.ai בלבד.** התוכנה מפעילה את Claude Code הרשמי במצב מבודד: בלי התוספים, בלי החיבורים ובלי ההגדרות שלך, עם Haiku, ורק עם כלי הרוטינות.
- **רוטינה לכל תזמון:** נוצרת בחשבון שלך, בלי חיבורים.
- **עלות:** כל פעולה עולה מעט מהמכסה, ולוקחת כ-10 שניות.
- **שעון:** claude.ai שומר שעות ב-UTC בלבד. כשפותחים את התוכנה אחרי החלפת השעון, השעות מתעדכנות לבד.

**GitHub.** התוכנה יוצרת ריפו, או משתמשת בריפו קיים, ומעלה אליו workflow שבודק את התזמונים.
- **הטוקן של הרוטינה:** נשמר כ-Secret מוצפן.
- **ריפו ציבורי:** בדיקה כל 10 דקות.
- **ריפו פרטי:** בדיקה כל 30 דקות, בגלל מגבלת הדקות החינמיות.
- **הרשאות הטוקן:** Contents, Workflows, Secrets ו-Actions, כולם Read and write. אם רוצים שהתוכנה תיצור את הריפו בעצמה, צריך גם Administration.

## אבטחה ופרטיות
- **איפה הטוקנים:** נשמרים במחשב, בתיקייה `%APPDATA%\ClaudeWake`, ובענן של המסלול: בקוד הסקריפט בגוגל, שגלוי רק לבעליו, או כ-Secrets ב-GitHub.
- **כתובת השלוחה:** כוללת מפתח סודי. אפשר להוסיף קוד כניסה ורשימת טלפונים מורשים.
- **מה הרוטינה מבצעת:** ההודעה מגיעה אליה מסומנת כ"מידע לא מאומת", והרוטינה מונחית לענות בקצרה בלי להפעיל כלים.

## מגבלות
- **מכסות:** כל הדלקה נספרת במכסת השימוש של המנוי.
- **הגבלה שעתית:** טריגר API מוגבל ל-30 הפעלות בשעה לכל רוטינה.
- **שלב ניסיוני:** הרוטינות וטריגר ה-API נמצאים ב-Research preview.
- **גוגל:** שומר עד 200 גרסאות לסקריפט, וכל שמירה יוצרת גרסה.
- **הסרה:** הסרת התוכנה לא מוחקת את מה שנוצר בענן. את הסקריפט מוחקים ב-script.google.com, את הרוטינות ב-claude.ai, ואת הריפו ב-GitHub.

## פיתוח
| מה | פקודה |
|---|---|
| בדיקות | `node --test tests/test_app.mjs tests/test_gas.mjs tests/test_settings.mjs tests/test_github.mjs` ו-`python -m unittest discover -s tests` |
| הרצה מול שירותים מדומים | `node tests/fake/dev.mjs` (או `--block` לנטפרי, `--noenv` לחשבון claude.ai ריק), ואז `http://127.0.0.1:8789/?t=dev` |
| בניית קובץ ההתקנה | `powershell -ExecutionPolicy Bypass -File installer\build-release.ps1 -Version 1.1.0` |

**מבנה:**
- `src/` הסקריפט לגוגל.
- `app/` התוכנה: `server.mjs`, ובתיקייה `lib/` מודול לכל מסלול.
- `github/` קובץ `wake.py` למסלול GitHub.
- `installer/` הבנייה.
- `tests/` הבדיקות וההדמיות.
