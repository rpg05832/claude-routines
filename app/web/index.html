הדלקת קלוד

    ברוכים הבאים

    התוכנה מגדירה פעם אחת מערכת קטנה בענן של גוגל, ששולחת הודעה קבועה ל-Claude Code:

    • בשעות שתבחר, כדי שחלון השימוש של 5 השעות יתחיל מראש
    • מהטלפון הכשר: מתקשרים לשלוחה בימות המשיח ומקישים 1

    אחרי ההגדרה המחשב לא צריך להיות דלוק. התוכנה הזאת נחוצה רק כדי לשנות הגדרות.

    צריך: חשבון גוגל, מנוי Claude (Pro או Max), ולטלפון גם טוקן API של ימות המשיח.

    חיבור לחשבון גוגל

    המערכת רצה ב-Google Apps Script בחשבון שלך, בחינם. לוחצים על הכפתור, בוחרים את החשבון בדפדפן ומאשרים.

    גוגל יבקש לאשר גישה ל-"clasp". זה הכלי הרשמי של גוגל להעלאת סקריפטים, והתוכנה משתמשת בו.

    הפעלת Apps Script API

    1. לוחצים על "פתיחת ההגדרות". נפתח דף של גוגל.
    2. ב-"Google Apps Script API" מעבירים את המתג למצב מופעל (On).
    3. חוזרים לכאן ולוחצים "בדיקה".

    יצירת המערכת בענן

    התוכנה יוצרת סקריפט בחשבון הגוגל שלך, מעלה אליו את הקוד ומפרסמת אותו. זה לוקח כחצי דקה.

      אישור הרשאות (פעם אחת): לוחצים "אישור הרשאות". בדף שנפתח:

      1. "Review permissions" (או "בדיקת הרשאות"), ובוחרים את החשבון
      2. אם מופיע "Google hasn't verified this app": לוחצים Advanced ואז Go to הדלקת קלוד (unsafe). זה הסקריפט שלך, לכן גוגל לא אימת אותו.
      3. Allow

      התוכנה בודקת לבד כל כמה שניות, וממשיכה כשההרשאות מאושרות.

      אם במקום זה מופיע "הדלקת קלוד פועלת", אפשר לסגור את הדף: ההרשאות כבר מאושרות.

      בעורך שנפתח: בתפריט הפונקציות למעלה בוחרים authorize, לוחצים Run (הפעלה) ומאשרים באותה דרך.

      חיבור ל-Claude

      1. לוחצים "פתיחת claude.ai", ושם New task. אם מופיע תפריט: Set up manually.
      2. שם: הדלקת קלוד. מודל: Haiku.
      3. בתיבת ההנחיה מדביקים את ההנחיה (כפתור "העתקת ההנחיה" כאן).
      4. ב-Trigger בוחרים API. ב-Advanced settings, בלשונית Connectors, מסירים את כל החיבורים.
      5. Create. מיד מופיע טוקן, פעם אחת בלבד: מעתיקים אותו לכאן. מעתיקים גם את Fire URL.

      מתי להדליק?

      בשעה הזאת תישלח הודעה לקלוד, וחלון השימוש יתחיל. אפשר להוסיף עוד שעות אחר כך בהגדרות.

      טיפ: שעה עגולה (07:00) מתחילה לפעמים באיחור של כמה דקות. עדיף כמה דקות אחרי.

      טלפון: ימות המשיח (לא חובה)

      מתקשרים לשלוחה, שומעים "להדלקת קלוד הקישו 1", מקישים, וההודעה נשלחת.

        כל מקש שולח הודעה קבועה לחיבור שבחרת. אותם מקשים משמשים לטלפון, לכפתורים ולתזמונים.

        תזמונים

        לפי שעון ישראל, כולל מעבר לשעון חורף. כל תזמון רץ פעם אחת ביום, ואם התעכב הוא עדיין ירוץ עד 20 דקות אחרי.

        ימות המשיח

        אחרי שינוי מקשים או משפט הפתיחה אין צורך לחבר שוב. חיבור מחדש נחוץ רק אחרי החלפת שלוחה או מפתח.
