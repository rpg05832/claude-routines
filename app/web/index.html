הדלקת קלוד

    ברוכים הבאים

    התוכנה מגדירה פעם אחת מערכת קטנה בענן ששולחת הודעה קבועה ל-Claude Code בשעות שתבחר, כדי שחלון השימוש של 5 השעות יתחיל מראש. במסלול גוגל אפשר גם להפעיל מהטלפון הכשר דרך ימות המשיח.

    אחרי ההגדרה המחשב לא צריך להיות דלוק. התוכנה הזאת נחוצה רק כדי לשנות הגדרות.

    איפה המערכת תרוץ?

    חיבור לחשבון גוגל

    המערכת רצה ב-Google Apps Script בחשבון שלך, בחינם. לוחצים, בוחרים חשבון בדפדפן ומאשרים.

    גוגל יבקש לאשר גישה ל-"clasp": הכלי הרשמי של גוגל להעלאת סקריפטים.

    הפעלת Apps Script API

    1. לוחצים "פתיחת ההגדרות". נפתח דף של גוגל.
    2. ב-"Google Apps Script API" מעבירים את המתג למופעל (On).
    3. חוזרים לכאן ולוחצים "בדיקה".

    יצירת המערכת בענן

    התוכנה יוצרת סקריפט בחשבון הגוגל שלך, מעלה אליו את הקוד ומפרסמת אותו. כחצי דקה.

      אישור הרשאות (פעם אחת)

      הסקריפט צריך את האישור שלך כדי לשלוח בקשות לקלוד ולהריץ תזמונים. מאשרים דרך טריגר חד-פעמי:

      1. לוחצים "פתיחת דף הטריגרים". נפתח דף הטריגרים של הסקריפט בגוגל.
      2. למטה בפינה: הוספת טריגר (Add Trigger).
      3. ממלאים:
        פונקציה להרצהauthorize
        פריסה להרצהHead
        מקור האירועמבוסס זמן (Time-driven)
        סוג הטריגרתאריך ושעה ספציפיים
        תאריך ושעה
      4. שמירה. גוגל מבקש לאשר הרשאות: בוחרים חשבון. אם מופיע "Google hasn't verified this app": Advanced, ואז Go to הדלקת קלוד (unsafe). זה הסקריפט שלך, לכן גוגל לא אימת אותו. ואז Allow.
      5. בשעה שנקבעה הטריגר רץ פעם אחת ונמחק לבד. ב"הרצות" (בסרגל הצד) יופיע "ההרשאות אושרו".

      השעה מתעדכנת כאן לבד, תמיד כמה דקות קדימה. אם עבר זמן מאז שהעתקת, מעתיקים שוב.

      אפשרות אחרת: , בחירת authorize ולחיצה על הפעלה (Run).

      חיבור לרוטינה ב-Claude

      1. "פתיחת claude.ai", ושם New task. אם מופיע תפריט: Set up manually.
      2. שם: הדלקת קלוד. מודל: Haiku. בתיבת ההנחיה מדביקים את ההנחיה ("העתקת ההנחיה").
      3. ב-Trigger בוחרים API. ב-Advanced settings, בלשונית Connectors, מסירים את כל החיבורים.
      4. Create. הטוקן מוצג פעם אחת בלבד: מעתיקים אותו לכאן, וגם את Fire URL.

      Claude Code במחשב

      התוכנה מנהלת את הרוטינות שלך ב-claude.ai דרך Claude Code הרשמי, עם ההתחברות שלך. כל פעולה (שמירה, שליחה) עולה מעט מהמכסה ולוקחת כ-10 שניות.

      נפתח חלון שחור. מתחברים בדפדפן שנפתח, ואם מבקשים, מדביקים את הקוד בחלון. אחר כך סוגרים אותו ולוחצים כאן "בדיקה".

      החשבון ב-claude.ai

      התוכנה מחפשת את סביבת הענן של החשבון שלך מתוך רוטינה קיימת.

      עוד אין רוטינות בחשבון. יוצרים אחת, פעם אחת:

      1. "פתיחת claude.ai", New task, Set up manually.
      2. שם כלשהו (למשל "בדיקה"), הנחיה כלשהי, ו-Create. אפשר לכבות אותה אחר כך.
      3. חוזרים ולוחצים "חיפוש שוב".

      חיבור ל-GitHub

      1. "יצירת טוקן" פותח את GitHub. Repository access: All repositories (או רק הריפו של הדלקת קלוד, אם כבר קיים).
      2. Permissions: Contents, Workflows, Secrets, Actions: כולם Read and write. כדי שהתוכנה תיצור את הריפו בעצמה, גם Administration.
      3. Generate token, מעתיקים ומדביקים כאן.
      פרטי: בדיקה כל 30 דקות (מגבלת הדקות החינמיות). ציבורי: כל 10 דקות; ההודעות והשעות גלויות, הטוקנים לא.

      מתי להדליק, ומה לשלוח?

      טיפ: שעה עגולה (07:00) מתחילה לפעמים באיחור של כמה דקות. עדיף כמה דקות אחרי. אפשר להוסיף עוד שעות אחר כך בהגדרות.

      טלפון: ימות המשיח (לא חובה)
